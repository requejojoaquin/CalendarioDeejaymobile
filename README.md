# CalendarioDeejaymobile
Calendario hecho a medida para deejaymobile una empresa de alquiler para eventos. Permite funciones básicas como creación de eventos, calendarios y etiquetas. Contiene vistas de tipo día, mes y año además de un botón para volver al día actual. Resolución para permitir a sus empleado visualizar los ventos con los equipos a cargar ocultando precios
